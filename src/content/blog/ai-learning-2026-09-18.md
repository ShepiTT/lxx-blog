# 第1期（2026-09-18）：从业务问题到AI方案

## 1. 业务流程图

<strong>知识讲解：</strong>流程图把一项工作按先后顺序画出来，并标明谁负责、用什么系统、产生什么结果。做产品设计前先画现状流程，再画优化流程，才能找出重复录入、等待和交接问题。

<strong>企业案例：</strong>原料入库可经过送货、仓库登记批次、品控抽样、检验、合格入库或不合格隔离。

<strong>参考做法：</strong>供应商送货 → 仓管登记批次 → 品控抽检 → 合格则入库并更新库存；不合格则隔离并通知采购、品控负责人。

<strong>可选练习：</strong>流程中发现同一批次信息被录入两个系统，先考虑什么改进？

<strong>参考答案：</strong>优先梳理能否扫码采集并通过接口同步，避免重复录入；这类问题未必需要大模型。

## 2. 量化业务痛点

<strong>知识讲解：</strong>把“麻烦、慢、容易错”转成次数、耗时、错误率和成本等指标，才能判断问题是否值得解决，也能比较上线前后的效果。

<strong>企业案例：</strong>假设每天手工录入 80 次，每次 2 分钟，每月工作 22 天，则每月耗时约 80×2×22÷60＝58.7 小时。

<strong>参考做法：</strong>如果优化后每次只需 30 秒，则约需 14.7 小时，理论上每月节省约 44 小时。数字应通过现场记录核实。

<strong>可选练习：</strong>除了耗时，还可以统计什么指标？

<strong>参考答案：</strong>录入错误率、返工次数、等待时间、涉及人数或追溯问题所需时间。

## 3. 用户故事

<strong>知识讲解：</strong>用户故事用“作为谁，我希望做什么，以便获得什么价值”描述需求，让开发团队理解用户和目标，而不是只收到一个功能名称。

<strong>企业案例：</strong>仓管员需要收原料时核对批次和采购单。

**参考做法：**“作为仓库管理员，我希望扫描原料批次码后自动显示采购单和供应商信息，以便减少手工录入和批次错误。”

<strong>可选练习：</strong>为品控人员写一条质检记录查询的用户故事。

**参考答案：**“作为品控人员，我希望按成品批次查询对应质检记录，以便快速核实产品是否满足放行要求。”

## 4. 验收标准

<strong>知识讲解：</strong>验收标准把“做完了”定义清楚。可用“给定某条件，当用户做某事，那么系统应……”描述正常和异常结果。

<strong>企业案例：</strong>仓管员扫描原料批次码后，系统需显示供应商、原料和日期信息。

<strong>参考做法：</strong>给定批次码有效，当仓管员扫描时，系统应在规定时间内显示关联信息；若无对应记录，则提示未找到并且不创建入库记录。

<strong>可选练习：</strong>扫码功能应增加一条什么异常验收标准？

<strong>参考答案：</strong>批次码无法识别时，系统应提示重新扫描或转人工确认，不能静默保存错误数据。

## 5. HTTP、REST API 与 JSON

<strong>知识讲解：</strong>API 是系统间按约定交换数据的接口。GET 常用于查询，POST 常用于新增或提交；JSON 是常见的数据格式。

<strong>企业案例：</strong>页面需要查询生产批次的质检结果。

<strong>参考做法：</strong>可定义 GET /api/batches/\{batchNo\}/quality-result，返回批次号、产品名、检验结果、检验人和时间。前端通过后端接口查询，不直接访问数据库。

<strong>可选练习：</strong>若要提交一条质检结果，通常使用 GET 还是 POST？

<strong>参考答案：</strong>通常使用 POST，因为这是提交或新增业务记录。

## 6. 判断问题是否需要 AI

<strong>知识讲解：</strong>确定规则和精确查询优先交给普通系统；理解自然语言、长文档或图片时再考虑 AI。高风险决定应由人员确认。

<strong>企业案例：</strong>按批次号查原料来源是数据库查询；从质检报告提取异常描述可以考虑 AI。

<strong>参考做法：</strong>批次查询由业务服务按数据库关系返回；AI提取报告信息后显示原文依据，由品控人员核对再保存。

<strong>可选练习：</strong>员工问“某制度如何规定”，优先考虑数据库查询还是知识库检索？

<strong>参考答案：</strong>通常考虑知识库检索，因为需要从制度文本中找相关内容并组织回答；回答应附来源，找不到依据时应说明。
