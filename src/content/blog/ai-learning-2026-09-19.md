# 第2期（2026-09-19）：把需求整理成可设计的数据与权限

## 1. 识别项目干系人

<strong>知识讲解：</strong>干系人包括使用系统、提供数据、审批项目或受项目影响的人。只听提出需求的人，容易遗漏关键规则和岗位需要。

<strong>企业案例：</strong>原料入库系统涉及仓管、采购、品控、财务、信息部门和仓储主管。

<strong>参考做法：</strong>分别确认仓管操作、采购单信息、品控放行、财务对账、接口维护和管理指标；指定最终业务验收人。

<strong>可选练习：</strong>生产异常系统至少找哪三类岗位访谈？

<strong>参考答案：</strong>异常上报的操作员、负责确认分派的班组长、负责质量或设备处置的专业人员。

## 2. 需求优先级

<strong>知识讲解：</strong>有限时间内要先实现关键需求。MoSCoW 可把需求分为 Must（必须）、Should（重要）、Could（可选）和 Won’t（本期不做）。

<strong>企业案例：</strong>生产异常系统的异常记录和处理闭环是核心；AI自动生成分析可后续验证。

<strong>参考做法：</strong>第一期确保异常类型、批次、责任人、状态和处理结果可记录、可查询；自动分析放入后续试点。

<strong>可选练习：</strong>语音输入异常描述通常属于哪个优先级？

<strong>参考答案：</strong>通常是 Could。它改善体验，但不具备时仍可用文字完成核心流程。

## 3. 数据字典

<strong>知识讲解：</strong>数据字典定义字段的含义、格式、必填要求和允许取值，避免不同部门对同一字段理解不一致。

<strong>企业案例：</strong>异常记录有批次号、异常类型、描述、上报人、时间和状态。

<strong>参考做法：</strong>状态统一为待确认、处理中、待验证、已关闭等固定值；不让用户随意输入“处理中”“正在处理”等同义词。

<strong>可选练习：</strong>严重程度字段如何避免含义模糊？

<strong>参考答案：</strong>设定低、中、高、紧急等选项，并为每级写出可判断的条件；必要时由制度或业务负责人确认定义。

## 4. 角色权限控制

<strong>知识讲解：</strong>按岗位角色设置查看、新增、修改、审核、删除和导出权限。遵循岗位只拿到完成工作所需权限的原则。

<strong>企业案例：</strong>操作员可上报异常，班组长可分派，品控人员可填写质量意见，管理员维护账号。

<strong>参考做法：</strong>已提交的关键质量记录不允许普通用户直接删除；通过作废流程保留原记录和操作痕迹。

<strong>可选练习：</strong>仓管员是否一定要看到产品采购价格？

<strong>参考答案：</strong>不一定。若完成收货无需价格，则不应默认开放；价格可仅向采购、财务等相关角色开放。

## 5. SQL 查询基础

<strong>知识讲解：</strong>SQL 用于查询和整理结构化数据。SELECT 选字段，FROM 指定数据表，WHERE 过滤条件，ORDER BY 排序。

<strong>企业案例：</strong>查询待处理的生产异常，可以取批次号、类型、发生时间，并按时间倒序排列。

**参考做法：**

```
SELECT batch_no, abnormal_type, occurred_at
FROM production_abnormal
WHERE status = 'pending'
ORDER BY occurred_at DESC;
```

<strong>可选练习：</strong>如只看高严重程度异常，应增加什么筛选？

<strong>参考答案：</strong>增加 AND severity = 'high'（实际取值应以公司的数据字典为准）。

## 6. RAG 企业知识库

<strong>知识讲解：</strong>RAG先检索企业文档中的相关内容，再让大模型依据这些资料组织回答。它适用于制度、SOP、操作手册等文档问答。

<strong>企业案例：</strong>员工询问包装封口异常处理方法，系统检索包装 SOP 和质量异常规定后回答。

<strong>参考做法：</strong>答案附资料名和章节；检索不到制度时明确说没有找到依据，并建议询问责任岗位；不能编造内部规定。

<strong>可选练习：</strong>若找到的制度版本已过期，系统应如何处理？

<strong>参考答案：</strong>标明版本和日期，优先检索经确认的现行文件；若无法确认现行版本，应提示用户人工核实，不把旧文件当作确定答案。
