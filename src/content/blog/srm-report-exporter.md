平时查扣款和客诉，总要进系统里翻。翻完还得自己整理，挺费劲。

于是做了个 Windows 小工具：「SRM 扣款与客诉导出」。主要面向鸣鸣很忙 SRM。下载一个 exe，放到打算长期用的目录里，双击就能开。

![软件界面（虚构数据示例）](/covers/srm-ui.png)

填好站点、登录后，按日期把扣款明细和客诉账单导成 Excel。日期可以用昨天、近 7 天、本月、上月快速填。扣款明细里本身就包含客诉扣款，客诉账单会把这部分单独列出来。源系统没给到的字段会留空，账单里也有说明。

![扣款明细导出示例（虚构数据）](/covers/srm-deductions.png)

![客诉账单导出示例（虚构数据）](/covers/srm-complaints.png)

还可以生成一份能离线打开的汇总报告。里面能看有效扣款合计、罚款升级情况、观察清单、人工确认率，以及还待供应商确认的单据。构成和趋势按扣款类型、按时间摊开来看。质检单和罚款也能对上，看看哪些门店前后几天里有升级。确认环节可以把待确认、今天到期，还有可能已经过期的单据筛出来。门店、地区和卸货费也能看一眼。

![离线汇总报告（虚构数据示例）](/covers/srm-summary.png)

嫌每天手动点太烦，可以设成每天或每周自动导出。每天导的是昨天的数据，每周导的是运行日前连续 7 天。这是用 Windows 的任务计划来跑的，电脑得开着、能联网，而且当前这个 Windows 用户得保持登录。需要定时跑的时候，可以把登录信息按当前用户加密保存在本机。导出成功后，也可以让汇总自动更新。

扣款和客诉这类数据，没必要再传到别处去。站点设置、登录信息和导出文件都留在这台电脑上。

先说清楚，它读取的是已授权账号在指定站点里的数据，汇总也按导出当时的口径来算，不是财务系统里的最终对账单。同一张扣款单如果出现在多个文件里，会优先留已确认的版本；作废的不算。导出区间里缺了哪几天，报告顶部会提示。清单状态以导出当时为准，有的过期单可能已经被系统自动确认了。日期上，程序按要求的扣款日期来，没有的时候才用创建日期。软件负责把数据拉下来、整理好，不负责替财务下结论。

它不能让扣款变少，也不能替你把单子都确认完。

但下次再想对账的时候，至少不用从零翻一遍了。
